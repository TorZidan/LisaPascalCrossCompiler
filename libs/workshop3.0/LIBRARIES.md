# Apple Lisa Workshop 3.0 Pascal Libraries & Units Reference

Complete reference of all **13 libraries**, **99 units**, **2,042 procedures and functions**, and **1,102 Clascal methods** (across **120 `SUBCLASS` classes** — **3,144 total callables**) in Apple Lisa Pascal Workshop 3.0 and the Lisa Office System / Toolkit.

## How `USES` and Library Linking Work

Lisa Pascal distinguishes between **plain unit `.obj` files** and **intrinsic libraries** registered in `libs/workshop3.0/INTRINSIC.LIB`:

### 1. Plain Unit `.obj` Files (`SYSCALL.obj`, `PASLIBCALL.obj`)

`SysCall` and `PasLibCall` are standalone unit object files rather than intrinsic libraries in `INTRINSIC.LIB`. Specify `{$U <filename>}` before the unit name in your `USES` clause, and include the unit when linking:

```pascal
PROGRAM FileDemo;
USES
  {$U SysCall} SysCall;
```

```sh
pascal/lpc.py --link=IOSPASLIB,SYSCALL FILEDEMO
```

### 2. Intrinsic Libraries (`INTRINSIC.LIB`)

Units inside intrinsic libraries (`SUlib.obj`, `iospaslib.obj`, `IOSFPLIB.obj`, `PRLib.obj`, `ObjIOLib.obj`, `Sys1Lib.obj`, `Sys2Lib.obj`, `TKLIB.obj`, `TK2LIB.obj`, `QPLIB.obj`, `LCORBGLIB.obj`) are automatically located via `INTRINSIC.LIB` whenever `{$U+}` is active (the Workshop 3.0 default). List the unit names directly in `USES` and pass the needed libraries to `--link=`:

```pascal
PROGRAM DrawDemo;
USES
  UnitStd, QuickDraw, Events, Windows;
```

```sh
pascal/lpc.py --link=IOSPASLIB,SYS1LIB DRAWDEMO
```

> [!NOTE]
> Four libraries in `libs/workshop3.0/` (`TKLIB.obj`, `TK2LIB.obj`, `QPLIB.obj`, `LCORBGLIB.obj`) are link-stripped stubs without embedded `INTERFACE` text; their unit interfaces documented here were extracted from the unstripped Workshop 3.0 / Lisa Office System build libraries.
