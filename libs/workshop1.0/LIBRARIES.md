# Apple Lisa Workshop 1.0 Pascal Libraries & Units Reference

Complete reference of all **8 libraries**, **59 units**, and **1,321 procedures and functions** in `libs/workshop1.0/` (Apple Lisa Pascal Workshop 1.0).

## How `USES` and Library Linking Work in Workshop 1.0

Compile for Workshop 1.0 (`$G-` 1.0/2.0 object/I-code conventions) by setting `LISA_BOOT=libs/workshop1.0` and passing `--2.0` to `pascal/lpc.py`:

### 1. Plain Unit `.obj` Files (`SYSCALL.obj`, `PASLIBCALL.obj`)

`SysCall` and `PasLibCall` are standalone unit object files with embedded `INTERFACE` text (not in `INTRINSIC.LIB`). Reference them with `{$U ...}`:

```pascal
PROGRAM FileDemo;
USES
  {$U SysCall.obj} SysCall;
```

```sh
LISA_BOOT=libs/workshop1.0 pascal/lpc.py --2.0 --link=IOSPaslib,SYSCALL FILEDEMO
```

### 2. Intrinsic Libraries With Embedded `INTERFACE` Text (`SULIB`, `IOSPASLIB`, `IOSFPLIB`)

In `libs/workshop1.0/`, `Sulib.obj` (`StdUnit`), `IOSPaslib.obj` (`PasLib`, `BlkIOIntr`, `BlockIO`, `PasHeap`), and `IOSFplib.obj` (`FPLib`) include `InterfLoc` blocks and compressed `INTERFACE` text, so `USES` resolves them automatically through `INTRINSIC.LIB` (note that `StdUnit` requires `{$SETC ForOS := TRUE}`):

```pascal
{$SETC ForOS := TRUE}
PROGRAM MathDemo;
USES
  StdUnit, FPLib;
```

```sh
LISA_BOOT=libs/workshop1.0 pascal/lpc.py --2.0 --link=IOSPaslib,Sulib,IOSFplib MATHDEMO
```

### 3. Packed Intrinsic Libraries Without Embedded `INTERFACE` Text

Unlike Workshop 3.0, the system and application libraries in `libs/workshop1.0/` (`Objiolib.obj`, `Sys1lib.obj`, `Sys2lib.obj`) contain packed MC68000 code and 30-byte `UnitBlock` headers without embedded `INTERFACE` text. When compiling on Workshop 1.0, programs specify separate unit `.obj` files via `{$U ...}` (such as `{$U QD/QuickDraw} QuickDraw`) and link against `Sys1lib.obj`:

```pascal
PROGRAM Boxes;
USES
  {$U QD/UnitStd} UnitStd,
  {$U QD/QuickDraw} QuickDraw;
```
