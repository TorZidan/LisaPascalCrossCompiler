# Apple Lisa Workshop 2.0 Pascal Libraries & Units Reference

Complete reference of all **9 libraries**, **84 units**, and **1,824 procedures and functions** in `libs/workshop2.0/` (Apple Lisa Pascal Workshop 2.0).

## How `USES` and Library Linking Work in Workshop 2.0

Compile for Workshop 2.0 (`$G-` 1.0/2.0 object/I-code conventions) by setting `LISA_BOOT=libs/workshop2.0` and passing `--2.0` to `pascal/lpc.py`:

### 1. Plain Unit `.obj` Files (`SYSCALL.obj`, `PASLIBCALL.obj`)

`SysCall` and `PasLibCall` are standalone unit object files with embedded `INTERFACE` text (not in `INTRINSIC.LIB`). Reference them with `{$U ...}`:

```pascal
PROGRAM FileDemo;
USES
  {$U SysCall.obj} SysCall;
```

```sh
LISA_BOOT=libs/workshop2.0 pascal/lpc.py --2.0 --link=IOSPASLIB,SYSCALL FILEDEMO
```

### 2. Intrinsic Libraries With Embedded `INTERFACE` Text (`SULIB`, `IOSPASLIB`, `IOSFPLIB`)

In `libs/workshop2.0/`, `SULIB.obj` (`StdUnit`), `IOSPASLIB.obj` (`PasLib`, `BlkIOIntr`, `BlockIO`, `PasHeap`), and `IOSFPLIB.obj` (`FPLib`) include `InterfLoc` blocks and compressed `INTERFACE` text, so `USES` resolves them automatically through `INTRINSIC.LIB` (note that `StdUnit` requires `{$SETC ForOS := TRUE}`):

```pascal
{$SETC ForOS := TRUE}
PROGRAM MathDemo;
USES
  StdUnit, FPLib;
```

```sh
LISA_BOOT=libs/workshop2.0 pascal/lpc.py --2.0 --link=IOSPASLIB,SULIB,IOSFPLIB MATHDEMO
```

### 3. Packed Intrinsic Libraries Without Embedded `INTERFACE` Text

Unlike Workshop 3.0, the system and application libraries in `libs/workshop2.0/` (`objiolib.obj`, `SYS1LIB.obj`, `sys2lib.obj`, `lcorbglib.obj`) contain packed MC68000 code and 30-byte `UnitBlock` headers without embedded `INTERFACE` text. When compiling on Workshop 2.0, programs specify separate unit `.obj` files via `{$U ...}` (such as `{$U QD/QuickDraw} QuickDraw`) and link against `SYS1LIB.obj`:

```pascal
PROGRAM Boxes;
USES
  {$U QD/UnitStd} UnitStd,
  {$U QD/QuickDraw} QuickDraw;
```
